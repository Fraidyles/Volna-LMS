# LMS «Медицина Долголетия» — бэкенд, этапы 1–5

Роли, приглашения по email, демо-курс, прогресс, очередь сертификатов, чат,
потоки и календарь эфиров (с повторами), сроки/блокировка доступа, скрытие
материалов по врачам, Dashboard с фильтрами. Плюс этап 5 —
**безопасность и эксплуатация**: rate limiting, XSS-санитайзер, отзыв токенов,
журнал действий **с откатом конкретных изменений главным администратором**,
бэкапы, черновики/история уроков, повторяющиеся эфиры, массовый CSV-импорт
врачей, «просмотр глазами врача», PWA, тёмная тема, автотесты (36/36 зелёных),
OpenAPI-документация на `/api-docs`.

Node.js + Express + PostgreSQL, фронтенд — HTML/CSS/JS без сборки.

## Задания, заказы, анкеты, лента ответов (как в GetCourse)

- **Задания к урокам.** Администратор в «Учебных материалах» → кнопка «Задание»
  у урока пишет формулировку и при желании включает «стоп-урок». Врач видит
  отдельный шаг урока «Задание» и отвечает текстом. Куратор в «Ответы врачей →
  Проверка заданий» принимает ответ или возвращает на доработку с комментарием
  (врач получает уведомление). Принятый ответ засчитывает урок; стоп-урок без
  принятого ответа не засчитывается ни кнопкой «Урок пройден», ни тестом урока,
  и держит итоговый тест курса (без принятых обязательных заданий курс не завершить).
- **Лента ответов.** Ответы на задания, отзывы о модулях и заполненные анкеты —
  одной лентой для куратора, с фильтром по типу.
- **Продукты и заказы.** «Продажи → Продукты» (администратор): цена, рассрочка
  до N платежей, курс, который открывается после полной оплаты. «Продажи → Заказы
  и оплаты» (куратор и администратор): заказ врачу с графиком платежей, отметка
  каждого платежа, просрочки. Статус оплаты врача («Оплачено/Частично/Не
  оплачено» на дашборде) теперь считается из его заказов автоматически; у врача с
  заказами ручная смена статуса недоступна. Отмена заказа или снятие отметки об
  оплате **не закрывает** уже открытый курс — прогресс врача не удаляется, закрыть
  доступ можно вручную во вкладке «Доступ».
- **Анкеты.** «Ответы врачей → Анкеты»: конструктор (один вариант, несколько,
  шкала 1–5/1–10, свободный ответ), аудитория — все врачи или записанные на курс.
  Врач видит анкету на главной и получает уведомление; персонал видит сводку по
  каждому вопросу и кто ответил.

Новые таблицы создаются сами при старте сервера (схема идемпотентна), отдельно
запускать `npm run migrate` после обновления не обязательно.

## Откат действий (для главного администратора)

Во вкладке «Журнал» у обратимых, ещё не откаченных действий есть кнопка
«Откатить» — видна только роли `super_admin`. Возвращает состояние к тому,
что было непосредственно перед этим действием: сроки/блокировка доступа,
выдача сертификата, видимость материалов, публикация/восстановление урока,
правки теста, приглашения, потоки, эфиры (включая целые серии повторов).

Действия без сохранённого «было» (например, сброс пароля — сам пароль
намеренно нигде не хранится) откатить нельзя, кнопка для них не появляется.
Каждый откат сам по себе записывается в журнал отдельной строкой.

## Автотесты

```bash
createdb lms_jest_test   # разовая подготовка тестовой базы
npm test
```
36 тестов: аутентификация и rate limiting, права доступа по ролям, серверный
подсчёт баллов теста, блокировка/скрытие контента, XSS-санитизация,
и отдельный набор на саму систему отката (самая рискованная часть — проверена
персонально на каждом типе действия).


Следующие этапы (потоки, календарь эфиров, ограничение доступа, dashboard) будут

## 1. Что нужно на сервере

- Node.js 18+ (проверить: `node -v`)
- PostgreSQL 13+ (проверить: `psql --version`)
- Доступ по терминалу — тот же, что использовали для сайта Volna

## 2. Установка

```bash
# распаковать проект на сервере, затем внутри папки:
npm install
cp .env.example .env
```

Откройте `.env` и заполните:

| Переменная | Что вписать |
|---|---|
| `DATABASE_URL` | строка подключения к вашей базе, например `postgres://lms_user:пароль@localhost:5432/lms` |
| `JWT_SECRET` | случайная строка — сгенерировать: `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"` |
| `ALLOWED_ORIGINS` | домен, на котором будет открываться сайт, например `https://edu.вашдомен.ру` |
| `BOOTSTRAP_ADMIN_EMAIL` / `BOOTSTRAP_ADMIN_PASSWORD` | email и пароль первого главного администратора — под этим войдёте в первый раз |

## 3. Создать базу данных (если её ещё нет)

```bash
sudo -u postgres psql -c "CREATE USER lms_user WITH PASSWORD 'ваш_пароль';"
sudo -u postgres psql -c "CREATE DATABASE lms OWNER lms_user;"
```

## 4. Миграция и сид (один раз)

```bash
npm run migrate   # создаёт таблицы
npm run seed      # загружает уроки/тест демо-курса и создаёт главного администратора
```

## 5. Запуск

Проверочный запуск:
```bash
npm start
```
Откройте `http://ваш-сервер:8790` — должна открыться страница входа. Войдите под
`BOOTSTRAP_ADMIN_EMAIL` / `BOOTSTRAP_ADMIN_PASSWORD` — попадёте в панель главного администратора.

Постоянный запуск (чтобы не падало при закрытии терминала), тем же способом, что и Volna —
например через `pm2`:
```bash
npm install -g pm2
pm2 start src/server.js --name lms-backend
pm2 save
```

## 6. Домен и HTTPS

Так же, как для Volna — Nginx как reverse proxy на порт из `.env` (по умолчанию 8790),
плюс `certbot` для HTTPS. Пример конфига Nginx:

```nginx
server {
    listen 80;
    server_name edu.вашдомен.ру;

    location / {
        proxy_pass http://localhost:8790;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```
Затем: `sudo certbot --nginx -d edu.вашдомен.ру`

## 7. Ежедневные бэкапы БД

```bash
chmod +x scripts/backup.sh
crontab -e
```
Добавить строку (бэкап каждую ночь в 03:00, старше 14 дней удаляются автоматически):
```
0 3 * * * cd /путь/к/lms-backend && ./scripts/backup.sh >> /var/log/lms-backup.log 2>&1
```
Проверить вручную, что бэкап реально снимается:
```bash
./scripts/backup.sh
ls -la backups/
```
Восстановление из бэкапа:
```bash
gunzip -c backups/lms_2026-01-15_030000.sql.gz | psql "$DATABASE_URL"
```

## 8. Проверка, что всё работает

```bash
curl http://localhost:8790/health
# должно вернуть {"ok":true}
```

Дальше откройте домен в браузере, войдите как главный администратор, во вкладке
«Команда» пригласите куратора/администратора по email, а в «Ученики» — выдайте
доступ первому врачу.

## Структура проекта

```
lms-backend/
  src/
    server.js       — точка входа
    db.js           — подключение к PostgreSQL
    schema.sql       — структура таблиц
    migrate.js       — применяет schema.sql
    content.js        — тексты уроков и вопросов демо-курса
    seed.js           — загружает контент курса + создаёт первого админа
    middleware/auth.js — проверка входа и ролей
    routes/           — auth, invites, staff, course, courses, calendar, protocols,
                        specializations, notifications, assignments (задания и лента),
                        orders (продукты, заказы, оплаты), surveys (анкеты)
  public/
    index.html, app.js, styles.css — фронтенд без сборки, отдаётся тем же сервером
```
